# fluenty-client

> **Live Deployment:** [https://fluenty-client.vercel.app](https://fluenty-client.vercel.app)  
> **Backend API:** [https://fluenty-server.vercel.app](https://fluenty-server.vercel.app)

Next.js frontend application for Fluenty — an IELTS preparation platform tailored specifically for Bangla speakers.

## Features
- **Next.js 16 (App Router)** with TypeScript & Tailwind CSS v4.
- **Bilingual Architecture**: Seamless instant toggling between natural Bangla and English.
- **Editorial Cambridge Design System**: Newsreader serif headings, Noto Sans Bengali, Inter typography, luxury glassmorphism, and dark/light modes.
- **Interactive Practice Suites**: Real-time speaking examiner call room, writing correction editor, timed reading/listening passages, and mistake notebook.

## Getting Started

```bash
# Install dependencies
npm install

# Configure environment
cp .env.example .env.local

# Run development server
npm run dev

# Build for production
npm run build
npm start
```
